3.9.0-live-stream-files
- Added live SSE chat-state streaming for partial Agent/final answers, with automatic long-poll fallback when hosting buffers SSE.
- Accepts arbitrary attachment types and sends non-image files as opaque staged attachments for metadata-first Skill routing.
- Raised safe Bridge payload allowance for staged files while retaining local workspace size limits.
- Compacted Calendar, Files, chat and side-panel CSS for a smaller, cleaner responsive workspace.
- Preserves the stable ZIP -> staged extract -> verify -> atomic activation update pipeline.
- owner_key and agent_token remain persistent across update/rollback; the management UI does not rotate them accidentally.
- PharData remains available as ZIP extraction fallback when PHP ZipArchive is unavailable.

3.4.0-smart-router-updater
===============
- Added authenticated `bridge-update.php` for remote status, ZIP install and rollback.
- Update packages use a manifest with SHA-256 hashes, safe relative paths, file/size limits and serialized update locking.
- Creates a server-side backup before every install or rollback; failed installs automatically restore the previous code.
- Preserves runtime config/tokens, messages, rate limits and browser-scoped chat history during code updates.
- Connect descriptor now advertises Bridge updater/rollback support and the current Bridge version.
- Activity UI understands the model's Direct-vs-Skills route decision and Skill-family selection.
- Refined ChatGPT-like spacing, typography, composer, activity panel and responsive/mobile safe-area behavior.
- Browser-scoped private chat history, draft persistence, conversation deletion, response stop and remote model Stop/Unload remain available.
