# AI Bridge 3.8 — Professional Chat UI

- پنل Activity هنگام کار Agent باز می‌ماند و ارتفاع ثابت با اسکرول خودکار دارد.
- پس از تکمیل پاسخ، پنل خودکار جمع می‌شود و با کلیک دوباره باز می‌شود.
- Route مستقیم و Agent از هم مشخص هستند.
- جزئیات تصمیم مدل، Skill، مقصد امن، زمان اجرا، حجم Observation، خطا و fallback نمایش داده می‌شود.
- Heartbeatهای داخلی `working` در Activity عمومی نمایش داده نمی‌شوند.
- تاریخچه گفتگوهای همین مرورگر در Sidebar حفظ می‌شود و زمان آخرین فعالیت هر گفتگو نمایش داده می‌شود.
- پیام‌های هر session همچنان در storage سمت Bridge نگهداری می‌شوند.

## ظاهر همراه LlamaForge 0.34

فونت چت و تقویم خواناتر، نوار کناری ساده‌تر، خانه‌های ماهانه بزرگ‌تر، فرم ثبت سریع با کنترل‌های مناسب لمس و نمایش موبایل بازتنظیم شد. این تغییر فقط CSS است؛ رفتار Activity، همگام‌سازی، توکن‌ها و Atomic updater همان نسخهٔ قبلی باقی است. امکانات فرم ویرایش تقویم محلی هنوز در رابط Bridge موجود نیست.
