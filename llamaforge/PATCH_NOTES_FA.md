# LlamaForge 0.18.1 — Chat First

مشکل لاگ 0.18.0 این بود که Qwen GGUF با حجم 0.92GB دانلود و انتخاب شده بود، اما دانلود checkpoint آموزشی قبل از اجرای chat شروع شده و `llama-server` هنوز اجرا نشده بود. در نتیجه کاربر برای حرف زدن با مدل عملاً منتظر فایل آموزشی چند گیگابایتی می‌ماند.

در 0.18.1 ترتیب قطعی شده است:

1. GGUF آماده شد → انتخاب مدل
2. اجرای llama-server و باز شدن Chat
3. دانلود/آماده‌سازی checkpoint آموزشی در پس‌زمینه
4. بعد از آماده شدن، پیام‌های کامل‌شده وارد LoRA learning می‌شوند

اگر GGUF از قبل روی دیسک باشد ولی checkpoint آموزشی ناقص باشد، دکمهٔ مدل «Load & chat» است و دانلود آموزشی دوباره جلوی Chat را نمی‌گیرد.

لاگ‌های جدید `[model:select]`, `[chat:start]`, `[brain:auto] background setup requested ...` ترتیب واقعی اجرا را مشخص می‌کنند.
